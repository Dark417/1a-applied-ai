# Vertex AI Agent Engine and GCP agent services

Vertex AI Agent Engine (part of the Vertex AI Agent Builder / Gemini Enterprise Agent Platform family) is Google Cloud's managed runtime and state layer for agents.

## Runtime

- Deploys agents built with ADK (AdkApp template), LangGraph (LanggraphAgent), LangChain, LlamaIndex, AG2, or custom Python classes.
- Handles scaling, auth, and exposes query and streaming endpoints; deployed with the Vertex AI SDK (client.agent_engines.create).

## Sessions

- Agent Engine Sessions store the ordered events of a conversation per user, managed by Google.
- ADK uses them through VertexAiSessionService(project, location, agent_engine_id).

## Memory Bank

- Memory Bank stores long-term memories scoped to a dict such as {"user_id": "..."}.
- Memories are generated by Gemini from session events (generate) or written directly (create), consolidated with existing ones, and retrieved with similarity search (retrieve).
- ADK uses it through VertexAiMemoryBankService; PreloadMemoryTool and load_memory read it.

## Retrieval

- Vertex AI RAG Engine: managed corpora (chunking, embeddings, vector store) queried with rag.retrieval_query; ADK's VertexAiRagRetrieval tool and Gemini's retrieval tool use it directly.
- Vertex AI Search: enterprise search over websites and documents, exposed to ADK as VertexAiSearchTool.
- Vector Search: a managed ANN index for custom embeddings.

## Safety, evaluation, observability

- Model Armor screens prompts and responses against a template: prompt injection and jailbreak, responsible AI filters, sensitive data protection, malicious URLs.
- The Gen AI evaluation service (vertexai evaluation, EvalTask) scores responses and agent trajectories with computation-based and model-based (autorater) metrics.
- Cloud Trace receives OpenTelemetry spans; Agent Engine can enable tracing for deployed agents.
